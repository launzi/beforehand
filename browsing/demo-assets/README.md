# Demo assets

Everything in this folder is synthetic. It exists so the demo page and the tests run from a fresh clone.

- `korea-maker-20261003-010959.db` is a browsing-history database for a fictional persona: a hobby maker learning Python and planning a small creative project. It has no name, employer or account. The visits were generated by a script. No real browser profile, person or account is in it.
- `korea-maker-20261003-010959.db.json` describes how that database was generated. Its first fields are `"synthetic": true` and `"fictional": true`.
- `cache-live-*.json` holds the saved results of one agent run against that synthetic history.

The database holds no credentials, API keys or personal data. How the fixture is generated is described in `browsing/web/fixtures/README.md`.
